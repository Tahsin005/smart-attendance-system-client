API Documentation - New Endpoints
This document provides details for the newly created endpoints to assist with frontend integration. All endpoints require a Bearer Token in the Authorization header.

1. Update Location
Updates the real-time location and logs movement if the distance threshold (2m) is met.

URL: /location
Method: POST
Payload:
{
  "lat": 23.8103,
  "lng": 90.4125
}
Success Response (200 OK):
{
  "success": true,
  "message": "Location updated successfully",
  "data": {
    "liveUpdated": true,
    "logged": true,
    "sessionId": 1
  }
}
2. List Employees (Admin)
Retrieves a list of all employees with optional email search.

URL: /admin/employees
Method: GET
Query Params:
email (Optional): Search string for email filtering (uses partial match).
Success Response (200 OK):
{
  "success": true,
  "message": "Employees retrieved successfully",
  "data": [
    {
      "id": 2,
      "email": "employee@example.com",
      "role": "EMPLOYEE",
      "created_at": "2024-02-04T10:00:00.000Z"
    }
  ]
}
3. List User Work Sessions (Admin)
Retrieves work sessions for a specific user with date range filtering.

URL: /admin/work-sessions
Method: GET
Query Params:
userId (Required): The ID of the employee.
startDate (Optional): Filter sessions from this date (YYYY-MM-DD).
endDate (Optional): Filter sessions until this date (YYYY-MM-DD).
Success Response (200 OK):
{
  "success": true,
  "message": "Work sessions retrieved successfully",
  "data": [
    {
      "id": 1,
      "user_id": 2,
      "work_date": "2024-02-04",
      "status": "WORKING",
      "start_time": "2024-02-04T08:00:00.000Z",
      "start_lat": 23.8103,
      "start_lng": 90.4125,
      "start_selfie_url": "https://cloudinary.com/..."
    }
  ]
}
4. Get Work Session Details
Retrieves full details of a session, including live location and all logged movement.

URL: /work-session/:id/details
Method: GET
Success Response (200 OK):
{
  "success": true,
